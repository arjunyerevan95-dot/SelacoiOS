# Build35 direct control editing
Edit controls: tap an individual button to select it; drag it to move; add a second finger and pinch to resize that same button (44–140pt). Its action is never triggered while editing. Extra contacts are ignored, and after a pinch either remaining finger is consumed until both are released. Orientation/background/cancel resets ownership. Existing slider remains an alternative. Save persists using existing settings; Cancel restores the exact snapshot. No default layout, action mapping or game data changes.
Portable gesture ownership/bounds/cancel tests, routing/persistence source checks, existing touch input and math tests passed locally. CI checks actual iOS Objective-C++ syntax before the full engine build. Device testing remains required for selection, drag, pinch, cancellation and saved-layout readback.
