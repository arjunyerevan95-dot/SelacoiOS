# Build34: on-device framegen comparison
Adds a top-left native FG ON/OFF button and a one-second live counter. Start using the existing temporal + framegen test choice; then compare in the same scene without restarting. OFF stops interpolation capture/submission but keeps resolution, temporal upscaling, VSync and cap identical for a controlled comparison. Other launch modes show renderer FPS but do not pretend runtime-only switching can create missing startup Vulkan prerequisites.
Render FPS counts engine renderer updates, not UI display-link ticks. FG encoded/s counts successful interpolation encoding/submission, not GPU completion or visible generated frames. Display FPS is explicitly unmeasured. No doubled-FPS claim. Toggle is session-only and does not overwrite saved settings or layouts. Pending GPU pairs still retire when disabled; fresh history warms up when reenabled.
Portable atomic/counter test and materialized-source contract checks pass locally. Actual UIKit compile runs in CI; phone testing still required. No claimed lag fix.
